# WebApps

A collection of web application templates.

## Templates

### React OIDC Template

A React web application template with OpenID Connect (OIDC) authentication configured.

**Location:** [`react-oidc-template/`](./react-oidc-template/)

**Features:**
- 🔐 OIDC Authentication (react-oidc-context + oidc-client-ts)
- ⚡ Vite build tooling
- 📝 TypeScript support
- 🎨 React 19

See the [React OIDC Template README](./react-oidc-template/README.md) for detailed setup instructions.
